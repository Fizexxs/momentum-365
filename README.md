# 🎓 EduWeb — Online Learning Platform

> A modern, responsive education and online learning website designed to provide learners with access to flexible courses, educational resources, and remote learning opportunities.

---

## 📌 Overview

**EduWeb** is a responsive educational website built to provide a modern online learning experience.

The platform presents different learning opportunities, course categories, educational content, blog articles, statistics, and contact information through a clean and interactive interface.

This project was developed as part of my continuous journey in **web development and software engineering**, with a focus on building practical, responsive, and user-friendly web interfaces.

---

- 🏠 Responsive landing page
- 📚 Online course categories

- 📖 Popular courses showcase

## 🌐 Website Sections

> 🏠 Home

- The landing section introduces the platform and provides users with an entry point to explore available learning opportunities.

> 📚 Categories

- The platform provides different learning categories including:

- Online Degree Programs
- Non-Degree Programs
- Off-Campus Programs
- Hybrid Distance Programs

> ℹ️ About

- An overview of the educational platform, highlighting its focus on flexible and skill-oriented distance learning.

> 🎓 Courses

- A selection of popular courses is displayed with information such as:

- Course title
- Difficulty level
- Duration
- Number of lessons
- Number of students
- Rating
- Course price

> 🎥 Video Section

- A dedicated video area provides an interface for presenting educational video content.

> 📊 Statistics

- The website includes a statistics section displaying platform-related metrics such as enrolled students, completed classes, satisfaction rate, and instructors.

> 📰 Blog

- The blog section provides educational and content-creation related articles.

> 📧 Contact & Newsletter

- Visitors can access contact information and subscribe to the platform's newsletter.

> 📱 Responsive Design

- EduWeb is designed to provide a consistent experience across different screen sizes, including:

- 💻 Desktop
- 💻 Laptop
- 📱 Mobile devices
- 📱 Tablets
